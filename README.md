# yanhekttool

在浏览器里搜索课程、筛选学期、扫描往年课程目录，并将扫描结果保存在本地供搜索使用。

**适用：桌面版 Microsoft Edge / Google Chrome。无需 Python、Node.js 或命令行。**

[下载源码 ZIP](https://github.com/Disc13/yanhekt-tool/archive/refs/heads/master.zip) · [反馈问题](https://github.com/Disc13/yanhekt-tool/issues)

> 非官方学习辅助工具，与延河课堂及学校无隶属关系。请仅访问自己有权观看的课程，遵守平台规则与课程资料的使用约定。

## 能做什么

- 在原站课程页适配课程与节次目录。
- 在扩展弹窗里搜索课程、按学期筛选，查看课程年份与节次。
- 手动扫描预设学年 ID 区间，缓存目录、停止后续扫，并合并本地与服务端搜索结果。
- 点击“打开课程页”“打开原站课时”，继续使用原站播放器。
- 对支持的视频，可选“▶ 播放”在站点页打开单画面播放器；不是原站双屏播放器。
- 随时关闭扩展功能；已保存的开关状态会保留。

本项目是浏览器扩展。本地录像下载、离线双屏播放请看独立项目 [yanhekt-local](https://github.com/Disc13/yanhekt-local)。

## 安装：四步完成

### 1. 下载并解压

点击上方“下载源码 ZIP”，或在仓库首页选择 **Code → Download ZIP**，然后解压。

找到包含 `manifest.json` 的文件夹，通常叫 `yanhekt-tool-master`。后面加载的是这个文件夹，不是 ZIP 文件，也不是单个 `manifest.json`。

### 2. 打开扩展管理页

将对应地址复制到浏览器地址栏并回车：

| 浏览器 | 地址 |
| --- | --- |
| Microsoft Edge | `edge://extensions` |
| Google Chrome | `chrome://extensions` |

打开页面上的 **开发人员模式 / Developer mode**。

### 3. 加载文件夹

点击 **加载解压缩的扩展 / Load unpacked**，选择第 1 步找到的文件夹。

看到“yanhekttool”卡片后，确认扩展已启用。可以在浏览器工具栏的扩展菜单里固定它，方便下次打开。

### 4. 登录原站并刷新

打开 [延河课堂](https://www.yanhekt.cn)，正常登录，再刷新页面。

打开一个课程页使用原站目录，或点击工具栏里的扩展图标搜索课程。登录只在原站完成，无需向扩展填写账号密码，也无需手动复制登录 Token。

## 怎么用

- **浏览课程**：在“课程搜索”输入关键词，可按学期筛选，再点“打开课程页”。
- **查看节次**：点“查看节次”，再点“打开原站课时”。原站入口用于双屏观看；“▶ 播放”只提供单画面。
- **已知课程 ID**：直接打开原站 `/course/12345`，再打开扩展可识别该课程；原“按 ID 查看”标签已移除。课程 ID 与 `/session/` 后面的课时 ID 不同。
- **关闭功能**：关闭弹窗右上角开关。若要还原页面先前显示的内容，再刷新原站页面。

扩展不恢复原站页面的学期筛选栏，也不改写原站的课程搜索请求。页面权限响应适配与节次目录适配仍保留；它们不改变服务器授权。

### 往年课程：先扫描，再搜索

1. 打开“年份扫描”，选择学年，点击“开始扫描”。扫描只由你手动触发。
2. 保持弹窗打开；每批完成后自动保存断点。“停止”会等当前批次结束，随后可继续扫描。
3. 切换到“课程搜索”，输入课程名、学院、学年或课程 ID，缓存命中会带“本地”标签；选择具体学期也会过滤相应缓存。
4. 点击“查看节次”，再选择原站课时入口或单画面播放。

支持的预设区间涵盖 2021–2022 至 2025–2026 学年，但 ID 区间来自已有样本，**不保证覆盖所有课程**。扫描只缓存目录，不下载录像；列表未显示、目录存在、有节次和录像可播放是不同情况，请以实际打开结果为准。

本地缓存关键词不包括教师和课程号，这两类仍由服务端搜索。未输入关键词时展示服务端列表；输入后本地结果最多展示 200 门，可缩小关键词继续找。分页说明只针对服务端结果。

扫描默认每批 100 个 ID，可在“年份扫描”选择 200 条 / 批；批间间隔为 150 毫秒，每批完成后保存断点。每批内部最多同时发出 20 个请求，不是 200 个请求瞬时并发；整批有 12 秒中止保护。遇到网络、登录或限流错误会停止，保留已完成批次的断点，不把失败 ID 当作不存在跳过。旧缓存继续沿用，无需因调整批次重新扫描。不要重复启动大量扫描，遵守平台规则。关闭弹窗不再继续调度，尚未完成的当前批次需下次重扫；这不是后台扫描服务。

“清空缓存”会删除扫描目录和断点，不影响登录状态或站点数据。扫描中暂不可清空或切换学年；缓存可能过时，需要重扫时先确认不再需要旧断点，再清空缓存。存储空间不足会显示错误，**报错时不要把尚未保存的结果当作已经落盘**。

## 更新

1. 下载新版源码，将其解压到固定位置，更新已加载目录中的文件。
2. 回到扩展管理页，在扩展卡片上点击 **重新加载 / Reload**。
3. 刷新所有已打开的延河课堂页面。

**扩展重新加载和网页刷新，两步都要做。** 已加载的文件夹不要随意移动或删除。

## 常见问题

**找不到 `manifest.json`，或提示无法加载？**

先确认 ZIP 已解压，再进入真正包含 `manifest.json` 的那一层目录。部分浏览器会将 ZIP 外面再包一层文件夹。

**安装了，但页面或弹窗没有变化？**

确认扩展已启用，原站已登录；重新加载扩展，再刷新原站页面。刚安装时已打开的旧页面也需要刷新。

**提示“页面脚本未就绪”或请求超时？**

打开并登录 `www.yanhekt.cn`，刷新站点标签页后再试。学校网络、平台维护和接口变化都可能影响请求。

**目录为空，是否说明没有课程权限？**

不一定。登录过期、课程无录像、平台规则或接口变化都可能产生空列表。扩展不能替你授予服务器端访问权限。

**往年课程在网站搜不到，但地址还能打开？**

列表检索和按 ID 取详情是不同入口。扫描可能找到列表中未显示的记录，但不保证录像仍在，也不代表你获得了新的访问许可。

**“▶ 播放”失败、只有一个画面或提示早期 MP4？**

页面内播放器是可选的单画面入口，不替代原站双屏。早期 MP4 暂不由此入口处理，请点击“打开原站课时”；不能仅凭资源域名判断录像已删除。

**手机、Firefox 可以用吗？**

本文提供的是桌面 Edge / Chrome 的解压缩加载方式；不提供其他平台的安装保证。

## 权限与隐私

- `storage`：保存扩展开关、扫描到的课程目录与续扫断点（`chrome.storage.local`）。
- `tabs / activeTab`：查找已打开的站点标签页，以及打开课程、课时页面。
- `scripting`：为已打开的站点页面准备扩展脚本，点击播放时注入随包发布的播放组件。
- 站点范围：`www.yanhekt.cn`、`cbiz.yanhekt.cn`。

扩展读取原站已有的登录状态，向原站接口请求课程与节次，播放时访问平台的视频服务。扫描缓存不保存密码或登录 Token。当前代码没有开发者服务器或统计上报功能，不提供复制带凭证视频直链的功能。播放组件随扩展打包，不在运行时从 CDN 下载可执行脚本。请只从你信任的来源加载扩展。

## 开发者

普通使用者不需要执行以下命令。修改代码后可用 Node.js 运行离线回归：

```sh
node --test tests/extension.test.cjs
```

测试不连接平台，不代表所有浏览器和课程均已通过实际播放验证。

第三方组件与固定版本校验值见 [vendor/README.md](vendor/README.md)。

安装方式参考 [Chrome 官方教程](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world) 与 [Edge 官方教程](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。
